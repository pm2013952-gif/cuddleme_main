JavaScript (JS vanilla)

JavaScript es el lenguaje de programación de los navegadores. Se usa en el desarrollo web para que una página reaccione a lo que hace la persona: clics, teclas, formularios y datos que llegan de un servidor. "Vanilla" significa JavaScript puro, sin librerías. En CuddleMe, por ejemplo, es lo que hace que el peluche de la página de inicio cambie de color mientras eliges.

HTML, CSS y JS: tres capas

Una página web se construye con tres lenguajes que se complementan. Piensa en un peluche: el HTML es el cuerpo, el CSS es el color y la ropita, y el JavaScript es lo que lo hace "hablar" cuando lo abrazas.

LenguajePapelEjemplo en CuddleMe
HTMLEstructura: qué contenido hayEl título, los campos de nombre y mensaje, la imagen del peluche
CSSEstilo: cómo se veEl rosa de la marca, la tipografía redondeada, los espacios
JSComportamiento: qué haceEl peluche cambia de color o de accesorio al elegir una opción

Conceptos básicos

  • Variables: guardan datos para usarlos después. Se declaran con let (el valor puede cambiar) o const (no se vuelve a asignar).
  • Funciones: bloques de código con nombre que se ejecutan cuando se necesitan.
  • Eventos: cosas que ocurren en la página, como click (hacer clic) o mouseover (pasar el cursor, también llamado hover). Con addEventListener se conecta una función a un evento.

Ejemplo práctico

El siguiente código usa una variable, una función y dos eventos. Pruébalo con el botón: haz clic para dar abrazos y pasa el cursor por encima para ver cómo cambia el color.

/* ==================== EJEMPLO DE JAVASCRIPT ==================== */
// Obtiene los elementos del botón y del texto que muestra el número de abrazos.
const boton = document.getElementById('btn-abrazo');
const salida = document.getElementById('salida-abrazo');
let abrazos = 0;                      // variable

// Aumenta en uno el contador de abrazos y actualiza el texto en pantalla.
function darAbrazo() {                // función
  abrazos = abrazos + 1;
  salida.textContent = 'Abrazos: ' + abrazos;
}

// Ejecuta la función cuando el usuario hace clic en el botón.
boton.addEventListener('click', darAbrazo);                                   // evento click
boton.addEventListener('mouseover', () => boton.style.background = '#8EC5E8'); // evento hover
boton.addEventListener('mouseout',  () => boton.style.background = '');
Abrazos: 0

Cómo se lee, paso a paso

  1. Con getElementById se buscan en el HTML el botón y el texto donde se mostrará el resultado.
  2. La variable abrazos empieza en 0.
  3. La función darAbrazo suma 1 a la variable y actualiza el texto en pantalla.
  4. Los eventos conectan el botón con las funciones: el clic llama a darAbrazo y el cursor cambia el color del botón.

jQuery

jQuery es una librería de JavaScript lanzada en 2006. Nació porque los navegadores de esa época interpretaban el JavaScript de formas distintas, y escribir código que funcionara en todos era difícil. jQuery ofrecía una manera corta y uniforme de hacerlo, con el lema de escribir menos y hacer más.

Sintaxis básica

El símbolo $ es la función principal de jQuery. El patrón siempre es el mismo: seleccionar un elemento y aplicarle una acción.

$('selector').accion();

$('#mensaje').text('Te quiero mucho');   // selecciona por id y cambia el texto
$('.tarjeta').hide();                   // selecciona por clase y oculta

Para usarla hay que cargar el archivo de jQuery antes de tu código, por ejemplo desde un CDN:

<script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>

Ventajas y desventajas frente a JavaScript moderno

Ventajas

  • Sintaxis corta y fácil de leer.
  • Efectos y animaciones listos para usar.
  • Hay mucho código y plugins existentes, por eso aún aparece en proyectos antiguos.

Desventajas

  • Es una descarga extra que hace la página más pesada.
  • Casi todo lo que resolvía ya existe en JavaScript moderno (querySelector, classList, fetch).
  • Los frameworks actuales usan otro enfoque y no dependen de jQuery.

Comparación: JS vanilla y jQuery

Efectos típicos

Dos efectos clásicos de jQuery: fadeIn (aparecer poco a poco) y slideToggle (abrir y cerrar deslizando). Pruébalos:

$('#btn-fade').on('click', function () {
  $('#caja').hide().fadeIn(600);        // el mensaje aparece suavemente
});
$('#btn-slide').on('click', function () {
  $('#panel').slideToggle(400);         // la lista se desliza abierta o cerrada
});

JSON (JavaScript Object Notation)

JSON es un formato de texto para representar datos. Es ligero, fácil de leer para una persona y fácil de procesar para casi cualquier lenguaje de programación. Por eso es el estándar para intercambiar datos entre aplicaciones y servidores: un peluche de CuddleMe, con su nombre, color y mensaje, puede viajar como JSON del formulario a la fábrica.

Estructura básica

  • Objeto: conjunto de pares clave-valor entre llaves { }.
  • Arreglo: lista ordenada de valores entre corchetes [ ].
  • Valores permitidos: texto, número, true o false, null, objetos y arreglos.
  • Regla clave: las claves y los textos siempre van entre comillas dobles.

Objeto de JavaScript y cadena JSON

Se parecen mucho, pero son cosas distintas: el objeto vive dentro del programa, y la cadena JSON es texto que se puede guardar o enviar.

Objeto JS

const peluche = {
  nombre: "Osito",
  color: "rosa",
  accesorios: ["lazo", "gorro"],
  ropita: "camiseta",
  mensaje: "Te quiero mucho",
  personalizado: true
};

Cadena JSON

{
  "nombre": "Osito",
  "color": "rosa",
  "accesorios": ["lazo", "gorro"],
  "ropita": "camiseta",
  "mensaje": "Te quiero mucho",
  "personalizado": true
}
DiferenciaObjeto JSJSON
ClavesCon o sin comillasSiempre con comillas dobles
Comillas simplesPermitidasNo permitidas
Funciones y comentariosPermitidosNo permitidos

Dos métodos convierten entre ambos: JSON.stringify(objeto) crea la cadena y JSON.parse(cadena) vuelve a crear el objeto.

Pruébalo

const texto = document.getElementById('entrada').value;
try {
  const objeto = JSON.parse(texto);   // Convierte el texto JSON en un objeto JavaScript.   // cadena JSON -> objeto JS
  salida.textContent = 'Válido. El peluche se llama ' + objeto.nombre;
} catch (error) {
  salida.textContent = 'JSON inválido: ' + error.message;
}

Cómo lo usan las aplicaciones web

Cuando una página necesita datos (por ejemplo, el estado de un pedido), el navegador envía una petición a un servidor o a una API. El servidor responde con texto en formato JSON, y el código de la página lo convierte en objetos para mostrarlo en pantalla. También funciona al revés: al enviar el formulario de personalización, la página manda los datos del peluche como JSON.

fetch('https://api.ejemplo.com/pedidos/1')
  .then(respuesta => respuesta.json())      // lee la respuesta como JSON
  .then(datos => console.log(datos.peluche.nombre));

Web hosting y dominios

Una página web es un conjunto de archivos. Para que otras personas la vean, esos archivos deben estar en un servidor conectado a internet (hosting), y alguien debe poder encontrarlos con un nombre fácil de recordar (dominio).

Web hosting

El hosting es el servicio que guarda tus archivos en un servidor que está encendido todo el tiempo y los entrega a quien los pida.

TipoCómo funcionaÚtil para
CompartidoVarios sitios comparten un mismo servidorSitios pequeños con poco tráfico y presupuesto bajo
VPSUna parte reservada de un servidor, con control sobre el sistemaProyectos que necesitan configuración propia
NubeRecursos repartidos en muchos servidores que crecen según la demandaSitios con tráfico variable o que deben escalar

Cómo funciona Vercel para sitios estáticos

Un sitio estático son archivos HTML, CSS y JS que no necesitan procesarse en el servidor, como este. Vercel es una plataforma en la nube pensada para publicarlos:

  1. Conectas tu repositorio de GitHub a Vercel.
  2. Vercel toma los archivos y los publica en su red de servidores repartidos por el mundo (CDN), así la página carga desde un lugar cercano.
  3. Te da una URL pública con el formato nombre-proyecto.vercel.app y HTTPS incluido.
  4. Cada vez que haces git push, Vercel vuelve a desplegar el sitio automáticamente.

Dominios

Un nombre de dominio es la dirección legible de un sitio (como cuddleme.com). Reemplaza a la dirección IP, que es un número difícil de recordar. Se compra por año a un registrador.

tienda.cuddleme.com
  • TLD (dominio de nivel superior): el final del dominio, como .com (comercial), .net (redes) o .org (organizaciones).
  • Dominio: el nombre que eliges, junto a su TLD.
  • Subdominio: una sección antes del dominio, como tienda en tienda.cuddleme.com, que sirve para separar partes del sitio.

Propagación DNS

El DNS es la "guía telefónica" de internet: traduce dominios a direcciones IP. Así ocurre una consulta:

  1. Escribes tienda.cuddleme.com en el navegador.
  2. El navegador y el sistema operativo buscan la IP en su memoria (caché). Si no la tienen, preguntan al resolver DNS de tu proveedor de internet.
  3. El resolver consulta a un servidor raíz, que lo envía al servidor del TLD (.com).
  4. El servidor del TLD indica cuál es el servidor DNS autoritativo del dominio, que guarda los registros reales.
  5. El servidor autoritativo responde con la dirección IP del hosting.
  6. El navegador se conecta a esa IP y recibe la página. La respuesta queda en caché por un tiempo.

Cuando cambias un registro DNS (por ejemplo, apuntar tu dominio a Vercel), los servidores del mundo no se enteran al instante: cada uno guarda la respuesta anterior hasta que vence su TTL (tiempo de vida). A ese reparto gradual se le llama propagación y puede tardar desde minutos hasta 48 horas.
